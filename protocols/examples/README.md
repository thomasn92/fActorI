# Protocol Examples

These files are minimal deterministic examples generated by `factori export-protocols`. They are
small interoperability fixtures, not complete run snapshots.

The examples intentionally preserve MVP boundaries:

- proof and experiment examples are deterministic interoperability fixtures, not evidence;
- the proof example remains `Conjecture`;
- the experiment example is a `NegativeResult`;
- claim examples do not inflate labels;
- artifact and protocol files are not verification evidence.

Use the matching schema under `../jsonschema/` when implementing decoders in another language.
Run `factori validate-protocol-examples` to validate every example against its exported JSON
Schema without mutating protocol files, run artifacts, or ledger history.
